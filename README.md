# 虛擬貨幣策略最佳化與回測平台

延伸碩士論文的投資組合最佳化研究，將 VLGWO、VLGA 與平行島嶼模型應用於虛擬貨幣交易策略，並以 Python 與 Streamlit 建立操作介面。

## 主要功能

- 串接 Binance 公開 K 線資料。
- 使用異質島群平行演化交易策略。
- 可設定各方法的島嶼數量、演化代數與搜尋參數。
- 支援指定期間回測，納入手續費與滑價。
- 比較策略與 Buy and Hold 的報酬、最大回撤及資產曲線。

## 使用技術

Python、Streamlit、Multiprocessing、Pandas、NumPy、Git。

## 研究與開發

核心最佳化方法延伸自個人碩士論文研究；平台整合與部分程式開發使用 AI 工具協助。

本儲存庫用於展示專案功能與實驗成果，核心研究程式碼保留於私人儲存庫。
